## Что такое ProCode

ProCode — ИИ-помощник для повседневных задач. Говоришь или пишешь — получаешь готовый результат.

Главный принцип — **максимально просто**. Одна кнопка — один ответ. Без регистрации ради пробы, без сложных настроек, без инструкций на двадцать страниц. ProCode для обычных задач, которые люди решают каждый день.

## Почему бесплатно

Для простых задач огромная модель не нужна — это как ехать за хлебом на грузовике. ProCode работает на бесплатных моделях, в том числе на локальных: модель крутится на компьютере пользователя, и за неё никто не платит. Модель в ProCode меняется одной настройкой, так что мы не привязаны ни к одному поставщику.

## Установка

```bash

```

```bash

bun install
```

## Модели

Поддерживаются 75+ провайдеров — OpenAI, Anthropic, Google, Mistral, Qwen,
любой OpenAI-совместимый адрес, и локальные модели через Ollama.

Локально:

```bash
ollama pull qwen3:8b
ollama serve
```

Приоритет отдаётся локальной модели. Если её нет, обращаемся к внешнему API.

## Голосовой слой

Мы пишем голосом, программа отдаёт текстом:

- слова-паразиты вырезаются кодом, а не моделью — одинаково каждый раз
- ошибки распознавания чинятся по списку
- модель ставит знаки препинания, делит на абзацы, разбирает смысл
- **имена, числа, даты, номера документов переносятся дословно**

Текст не хранится. Ни логов, ни резервных копий, ни обучения.
